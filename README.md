# Valore Immobili

Mini-sito SEO + form lead + admin per valutazioni immobiliari a **Monza e Brianza**.

- **Live:** https://valore-immobili.it  
- **App:** cartella [`web/`](web/) (Next.js — root directory su Vercel)  
- **Documentazione:** [`docs/README.md`](docs/README.md)

## Quick start

```bash
cd web
cp .env.example .env.local   # se non l’hai già
npm install
npm run dev
```

Apri http://localhost:3000.

Dettagli env, DB e admin: [`web/README.md`](web/README.md).
